# 课件讲解助手 · 核心版

把 PPT / PDF 课件写成逐页中文讲解稿或可直接抄的复习笔记。

## 功能

- **课件导入**：支持 PPT / PDF；一次可选多份，自动合并、去重、按讲课顺序重排。
- **逐页讲解**：每页保留课件截图，配中文详解，讲清这一页在说什么、公式怎么推、图表怎么看、哪里容易错。
- **讲解深度**：简明 / 标准 / 深入 / 极致四档；可先做全章概览，也可追加章末总结、例题和自测。
- **看图讲解**：多模态模型会同时看页面截图，公式页和图表页更准。
- **英文课件**：自动翻译 / 总是翻译 / 不翻译；命中英文的页会生成一张中文版幻灯片，再配中文讲解。
- **笔记模式**：自动生成复习笔记，也支持套用笔记模板；保留小标题和编号，方便直接抄。
- **讲义库**：按课程 / 合集管理多份讲义，支持搜索、进度查看和继续上次的项目。
- **页内标注**：可在课件页上划线、框选、手写、写批注；导出 Word 时会把标注画进对应页图。
- **Word 导出**：课件页图 + 讲解正文，公式为 Word 原生公式；可开关封面、目录、图注、页码、页图边框和阴影。
- **断点续跑**：每页生成后立即保存，中途停下不丢进度；失败页可以单独重跑。
- **试跑与预估**：可先试跑前 5 页；开始前给出页数、费用和耗时预估。
- **模型渠道**：豆包、WorkBuddy、DeepSeek、通义千问、Kimi、智谱、硅基流动、本地 Ollama 等，均可自行配置。

## API Key

压缩包内没有 API Key，也没有预填的配置文件；第一次打开时所有渠道的 Key 输入框都是空白的，包括本地 Ollama。填过的 Key 只在本机用 Windows DPAPI 加密保存；换电脑或换 Windows 用户后会按未填写处理，界面显示空白。
